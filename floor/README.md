# 筑间 · 建筑建模工作台

电脑需要 Node.js 22.13 或更新的受支持版本。首次下载源码后运行 `npm ci` 和 `npm run build`，再双击 `启动筑间.vbs`，浏览器打开 `http://127.0.0.1:4178/`。启动器使用本地 `dist`，后续启动无需重新安装依赖。

已实现：

- 图片与 PDF 指定页导入，两点校准尺寸、识别范围选择。
- 本地识别实心墙、双线墙、柱体和候选门窗；自动适应图纸深浅，保留连接墙角的短墙段。
- 识别结果叠加原图预览，绿色默认选中、橙色待确认，点线条可切换；支持替换旧的自动识别结果与撤销。
- 连续画墙、矩形房间、门窗真实开洞、墙长厚度高度修改、相邻墙角联动。门窗放置后自动选中，可拖动洞口两端调整宽度，在右侧精确输入宽高；门提供“左右翻转”和“内外翻转”，平面、三维及导出同步更新。超出墙高或与其他门窗重叠时提示原因，不会静默改回尺寸。三维选中门窗后可按 S 或点“缩放”，拖侧边改宽、顶边改高、顶角等比缩放；M 或“移动”沿墙调整位置，Esc 取消拖动。平面单选门、楼梯或家具显示侧边悬浮工具，多选隐藏。
- 楼层栏“＋”右侧的“手动修复”：点击后在画布上方展开修复工具栏，提供断开墙、连接墙、补画墙、补地面、调整墙和自动补分区。说明在鼠标悬停时显示，移开隐藏；右侧显示当前步骤的完成、撤回和退出操作。手工分区可拖角点调整、改名、换材质、删除，操作支持撤销。
- 顶栏“建模工具”：画矩形或多边形生成柱子、地台、柜体；点击“三维推拉”，在透视视角直接点选并拖动顶面、侧面或墙端面；顶面改高度，侧面改轮廓或墙厚，墙端面改长度。橙色表示当前面，浮动距离框支持正数拉出、负数推入，Enter 应用；Shift 拖动精调，Esc 取消拖动，Ctrl+Z 撤销，完成后恢复旋转。墙角和房间联动，越界、轮廓交叉、挤到门窗或修改锁定内容时拒绝操作。当前不支持在曲面家具上任意推拉或局部画面挖洞。自建构件支持移动、轮廓角点调整、成组、复制、隐藏、锁定及导出。
- “建模工具 → 轮廓偏移”：选中房间，输入向内偏移宽度，预览并生成吊顶边、踢脚线或平台边框。偏移不会改动原房间；过大的宽度会提示调整。
- “建模工具 → 剖切面”：按高度、X 或 Y 方向剖切，拖滑块或三维中的蓝色手柄移动切面，可切换保留侧。剖切仅影响查看和截图，模型文件导出保留完整几何。
- “建模工具 → 视角与场景”：保存视角、当前楼层、剖切、屋顶、隐藏状态及显示设置；切换、更新或删除场景，并导出当前三维 PNG。场景随项目 JSON 和浏览器自动保存，不复制模型几何。
- 房间计算能容忍小范围的图纸断线；点击漏掉的闭合区域可补出独立地面，三维选取不再被底图挡住。
- 多楼层、复制楼层、最后一层清空（可撤销）、直跑楼梯、分层展示、搭建动画、三种简单屋顶。
- 原 `/floor` 的家具模型、平面图例、地面材质；拖家具本体移动，拖四角等比缩放，拖边中点单独改宽度或进深，也可输入尺寸或按 10% 放大、缩小。
- 家具拖近横竖墙面可贴墙，靠近其他家具可对齐边缘或中心，显示蓝色吸附线；关闭“吸附”后可自由移动。
- 框选、Shift 多选、成组与解组；组合可整体拖动、旋转、镜像、复制，门窗随选中的墙移动或复制。
- 输入毫米数精确移动、设置离横竖墙的净距、按横纵间距复制多份；可添加、拖动和锁定参考线，墙端与家具共用参考线吸附。
- 构件列表按墙体、门窗、家具、分区、楼梯筛选；隐藏同步作用于平面与三维，锁定防止拖动、修改或删除。组合、参考线和状态随项目保存。
- 鸟瞰、剖切、漫游、门开关、墙体碰撞；楼梯连接相邻楼层。
- 浏览器自动保存，完整项目 JSON 导入导出，旧 `/floor` JSON 迁移，GLB / STL / PNG / SVG 导出。
- “导出 → 漫游网页 · HTML（离线）”：生成包含当前建筑和三维引擎的单个 HTML 文件，双击可打开，也可直接发送给别人。支持室内行走、鼠标或触屏转向、开关门、切换房间和楼层、建筑总览及全屏；无需运行工作台或联网加载资源。文件包含完整模型，不含图纸底图，模型修改后需要重新导出。

导入图纸后可直接“先识别建模”，无需先校准；此时长度和面积按估算值显示。知道真实尺寸时，按画面提示点选标注线两端，输入图纸数字并选择毫米或米，也可同步修正本层模型的平面尺寸。选择构件后右侧改参数。`Esc` 结束画墙，`Ctrl+Z` 撤销，`Delete` 删除选中构件。手机属性按钮在右上角。

界面使用暖灰画布、偏白面板和灰蓝主色；橙色边框表示当前选中，蓝色虚线表示拖动时的吸附位置。

修复时，“补地面”沿边界依次点选角点，点击起点、按 Enter 或点击“完成分区”闭合；Backspace 或 Ctrl+Z 撤回未完成的角点，Esc 退出。轮廓交叉或与已有房间重叠时会提示调整。“断开墙”点击切分位置，不能切穿门窗；“连接墙”选择两个端点后确认连接，原有门窗保留。手工分区在重新计算房间时保留。

楼层栏“＋”右侧的“框选”默认只选家具，可在右侧切换范围；拖框选择完全落在框内的构件。Shift 点选可增减选项；选中后右侧“成组”，点组内任一构件即可操作整组。Ctrl+G 成组，Ctrl+Shift+G 解组，Ctrl+D 复制；方向键移动 10 毫米，Shift+方向键移动 100 毫米。参考线也在“＋”右侧添加；精确移动、旋转、镜像、等距复制和离墙净距在右侧“属性与编辑”中。间距是相同位置之间的距离，新增份数不包含原件；门窗单独复制需沿所属墙方向，越界或相互重叠会取消整次操作。

右上“构件列表”可显示隐藏对象、解锁底图或构件。隐藏、锁定整组时会作用于所有成员；隐藏墙也隐藏其门窗，隐藏门窗保留原洞口。隐藏仅用于编辑显示，GLB / STL 仍导出完整模型；截图与 SVG 按当前显示状态导出。

图纸只在浏览器处理。自动保存属于当前浏览器和访问地址，不会同步到云端；需要备份或换电脑时保存项目 JSON。

重新识别时，默认替换本层旧的自动墙及其门窗（包括后续修改），保留手画墙和家具。也可选择追加，但可能重复。预览中取消不会改动模型；应用后可用 `Ctrl+Z` 恢复。

CAD 导入：点“导入图纸”选择 ASCII DXF，确认文件单位与墙体图层；一张图包含多层时，框选当前楼层的范围。双线墙提取中线，单线墙按指定墙厚生成；绿色墙线会加入，黄色线点击确认，蓝色虚线为推测门洞。确认预览后生成可编辑模型，支持撤销和重新导入时替换上一次 CAD 墙体。CAD 参考线可单独隐藏或移除，随项目 JSON 保存。支持模型空间的直线、多段线、旋转与嵌套图块；圆弧保留为参考线，文字、标注和填充不转为墙体。DWG 和二进制 DXF 需先另存为 ASCII DXF；外部参照需先在 CAD 中绑定。图片/PDF 的识别入口仍然保留。

当前边界：图片识别面向清晰的横竖墙线图，尚不支持可靠识别斜墙、弧墙和透视照片；DXF 直线墙支持任意平面角度。复杂家具、洁具轮廓仍可能误判，候选门窗的类型和尺寸需要核对。屋顶按顶层外包矩形生成。楼梯完全位于上一层某个房间内时自动开楼板洞。原户型的开放空间分区保留原图定义。STL 单位为米，尚未做打印封闭性修复。

开发与验证：

```sh
npm ci
npm run dev
npm test
npm run test:browser
npm run build
```

`npm run test:browser` 使用 Playwright Chromium；测试截图和报告位于 `.qa/`。`dist/` 为静态发布目录，单独构建默认使用相对路径。在 courtyard-studio 仓库中，根目录的 `npm run build:floor` 使用 `/floor/` 作为资源前缀并复制到网站的 `dist/floor`，兼容带或不带末尾斜杠的入口。
