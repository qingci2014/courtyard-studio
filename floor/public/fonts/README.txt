Noto Sans SC (SIL Open Font License; see LICENSE.NotoSansCJK)
Source: https://github.com/notofonts/noto-cjk
Original: Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf
NotoSansSC-Regular.ttf is a static wght=400 instance generated with fontTools.
The full TrueType font is embedded in PDF output to avoid fontkit subset glyph corruption.
Fonts are served locally. PDF export does not contact a font service.
